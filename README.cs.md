# SunamoLogMessage

## Short description

Malý balíček pro Windows s abstrakcemi logovacích zpráv (ILogMessage, LogMessageAbstract, LogServiceAbstract) a generátorem WPF ovládacího prvku. Závisí na Microsoft.Extensions.Logging.Abstractions. Testovací projekt obsahuje jen šablonový UnitTest1.
